<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/AstroPulse/raw/main/icon.png" width="35"/> AstroPulse</h1>

<p align="center">
  A modern horoscope web application offering daily, weekly, and monthly zodiac predictions for mindful living. 
</p>

## <img src="https://github.com/KrishBharadwaj5678/AstroPulse/raw/main/assets/readme/features.gif" width="35"/> Features

| Feature              | Description                                                                 |
|------------------------|---------------------------------------------------------------------------------|
| ✨ **Real Time Horoscopes** | Get fresh and accurate predictions—**daily**, **weekly**, and **monthly**     |
| ♈ **Zodiac Customization** | Select your sun sign to receive **personalized horoscopes**                   |
| 🌐 **Multi-language Support** | Powered by **Deep Translator** to deliver horoscopes in **your language** |
| 🧘 **Mindful Living Tips** | **Suggestions** aligned with planetary energy for self-growth and awareness     |

## <img src="https://github.com/KrishBharadwaj5678/AstroPulse/raw/main/assets/readme/gettingStarted.gif" width="35"/> Getting Started

### 1️⃣ Clone the Repository
   
   ```bash
   git clone https://github.com/KrishBharadwaj5678/AstroPulse.git
   ````

### 2️⃣ Navigate to the Project

   ```bash
   cd AstroPulse
   ```

 ### 3️⃣ Install the Required Dependencies

   ```bash
   pip install -r requirements.txt
   ```

### 4️⃣ Run the Application

   ```bash
   streamlit run app.py
   ```
