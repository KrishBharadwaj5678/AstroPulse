<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/AstroPulse/raw/main/icon.png" width="35"/> AstroPulse</h1>

<p align="center">
  毎日・毎週・毎月の星座占いを提供し、より豊かでマインドフルな暮らしをサポートするモダンな占いWebアプリケーションです。
</p>

![AstroPulseDemo](https://github.com/KrishBharadwaj5678/AstroPulse/raw/main/AstroPulseDemo.png)

<img src="https://github.com/KrishBharadwaj5678/AstroPulse/raw/main/assets/readme/divider.gif" width="100%"/>

## <img src="https://github.com/KrishBharadwaj5678/AstroPulse/raw/main/assets/readme/features.gif" width="35"/> 主な機能

| 機能 | 説明 |
|------|------|
| ✨ **リアルタイムの星座占い** | **毎日・毎週・毎月**更新される最新かつ正確な占いを提供します。 |
| ♈ **星座のカスタマイズ** | あなたの星座を選択して、**パーソナライズされた占い**を受け取れます。 |
| 🌐 **多言語対応** | **Deep Translator** を利用し、占いを**お好みの言語**で表示できます。 |
| 🧘 **マインドフルネスのヒント** | 惑星のエネルギーに基づいた**自己成長と心の調和**のためのアドバイスを提供します。 |

## <img src="https://github.com/KrishBharadwaj5678/AstroPulse/raw/main/assets/readme/gettingStarted.gif" width="35"/> はじめに

### 1️⃣ リポジトリをクローン

```bash
git clone https://github.com/KrishBharadwaj5678/AstroPulse.git
```

### 2️⃣ プロジェクトディレクトリへ移動

```bash
cd AstroPulse
```

### 3️⃣ 必要な依存関係をインストール

```bash
pip install -r requirements.txt
```

### 4️⃣ アプリケーションを起動

```bash
streamlit run app.py
```
