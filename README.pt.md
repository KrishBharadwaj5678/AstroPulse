<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/AstroPulse/raw/main/icon.png" width="35"/> AstroPulse</h1>

<p align="center">
  Um aplicativo web moderno de horóscopos que oferece previsões diárias, semanais e mensais para todos os signos do zodíaco, promovendo uma vida mais consciente e equilibrada.
</p>

![AstroPulseDemo](https://github.com/KrishBharadwaj5678/AstroPulse/raw/main/AstroPulseDemo.png)

## <img src="https://github.com/KrishBharadwaj5678/AstroPulse/raw/main/assets/readme/features.gif" width="35"/> Funcionalidades

| Funcionalidade | Descrição |
|----------------|-----------|
| ✨ **Horóscopos em Tempo Real** | Receba previsões atualizadas e precisas — **diárias**, **semanais** e **mensais**. |
| ♈ **Personalização do Signo** | Escolha o seu signo para receber **horóscopos personalizados**. |
| 🌐 **Suporte a Múltiplos Idiomas** | Utiliza o **Deep Translator** para fornecer horóscopos **no seu idioma**. |
| 🧘 **Dicas para uma Vida Consciente** | **Sugestões** alinhadas com a energia dos planetas para promover o autoconhecimento e o bem-estar. |

## <img src="https://github.com/KrishBharadwaj5678/AstroPulse/raw/main/assets/readme/techStack.gif" width="35"/> Tecnologias Utilizadas

| Tecnologia | Finalidade |
|------------|------------|
| <img src="https://skillicons.dev/icons?i=python" width="25"/> **Python** | Linguagem principal que impulsiona toda a aplicação. |
| <img src="https://streamlit.io/images/brand/streamlit-mark-color.svg" width="25"/> **Streamlit** | Criação de uma interface web interativa e fácil de usar. |
| <img src="https://www.svgrepo.com/show/354202/postman-icon.svg" width="25"/> **Requests** | Obtém dados de horóscopos a partir de APIs externas. |
| <img src="https://github.com/KrishBharadwaj5678/AstroPulse/raw/main/assets/readme/google.png" width="25"/> **Deep Translator** | Traduz o conteúdo dos horóscopos para vários idiomas. |

## <img src="https://github.com/KrishBharadwaj5678/AstroPulse/raw/main/assets/readme/gettingStarted.gif" width="35"/> Como Começar

### 1️⃣ Clone o Repositório

```bash
git clone https://github.com/KrishBharadwaj5678/AstroPulse.git
```

### 2️⃣ Acesse o Diretório do Projeto

```bash
cd AstroPulse
```

### 3️⃣ Instale as Dependências Necessárias

```bash
pip install -r requirements.txt
```

### 4️⃣ Execute a Aplicação

```bash
streamlit run app.py
```
