<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/AstroPulse/raw/main/icon.png" width="35"/> AstroPulse</h1>

<p align="center">
  Современное веб-приложение с гороскопами, предлагающее ежедневные, еженедельные и ежемесячные прогнозы для всех знаков зодиака, способствующие осознанной жизни.
</p>

## <img src="https://github.com/KrishBharadwaj5678/AstroPulse/raw/main/assets/readme/features.gif" width="35"/> Возможности

| Возможность | Описание |
|-------------|----------|
| ✨ **Гороскопы в реальном времени** | Получайте актуальные и точные прогнозы — **ежедневные**, **еженедельные** и **ежемесячные** |
| ♈ **Персонализация по знаку зодиака** | Выберите свой знак зодиака, чтобы получать **персонализированные гороскопы** |
| 🌐 **Поддержка нескольких языков** | Благодаря **Deep Translator** гороскопы доступны **на вашем языке** |
| 🧘 **Советы для осознанной жизни** | **Рекомендации**, основанные на влиянии планет, для личностного роста и внутренней гармонии |

## <img src="https://github.com/KrishBharadwaj5678/AstroPulse/raw/main/assets/readme/gettingStarted.gif" width="35"/> Начало работы

### 1️⃣ Клонируйте репозиторий

```bash
git clone https://github.com/KrishBharadwaj5678/AstroPulse.git
```

### 2️⃣ Перейдите в каталог проекта

```bash
cd AstroPulse
```

### 3️⃣ Установите необходимые зависимости

```bash
pip install -r requirements.txt
```

### 4️⃣ Запустите приложение

```bash
streamlit run app.py
```
